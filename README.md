# INVENTORY MANAGEMENT

A simple Inventory Management System built with PHP & MySQL for small stores.
Every sale, stock-in, and stock-out updates in real-time to prevent out-of-stock and overstock.

## Features
- Dashboard with Low Stock Alerts
- Inventory Management - Add, Edit, Delete Products
- Sales / POS Transaction
- Stock In / Stock Out Tracking
- Sales Reports

## Tech Stack
- PHP, MySQL, HTML, CSS, JavaScript, Bootstrap

## How To Run
1. Copy folder to C:/xampp/htdocs/
2. Start Apache and MySQL in XAMPP
3. Import database in phpMyAdmin
4. Open http://localhost/INVENTORY-MANAGEMENT
